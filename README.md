# استوديو الثمبنيل — رؤية

يأخذ فيديو (رابط درايف / رابط خارجي / مسار على الجهاز / رفع) ويطلّع:
- ثمبنيل يوتيوب 1280×720
- ثمبنيل ستوري 1080×1920

بخط Handicrafts Bold مع تمديد وستايل طبقات متغيّر بألوان هوية رؤية.

## التشغيل (ويندوز)
المتطلبات: Python 3.10+ و ffmpeg في الـ PATH.

```bash
run.bat
```
أو يدوياً:
```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python app.py
```
ثم افتح http://127.0.0.1:5055

## ملاحظات
- فيديو من الجهاز (مسار مكتوب): الصور تتحفظ في نفس فولدر الفيديو.
- فيديو من الدرايف/رابط/رفع: زر "اختر مكان الحفظ" (Chrome/Edge).
- الخطوط والشعار داخل `fonts/` و`static/` ملكية رؤية / مرخّصة، فاحتفظ بالمستودع **Private**.
